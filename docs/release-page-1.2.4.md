Each one holds MechWarrior 3, Pirate's Moon, MechWarrior 1 Remake and the launcher (named BattleTech).

## Before you install

- **You need your own games.** No game files are included: the launcher sets each game up from your install, disc or disc image, and copies what it needs.
- **Upgrading from any earlier version:** install over it. Your pilots, saves, settings and mods are kept.
- **Mac:** the first time, macOS stops the app because it isn't signed. Open System Settings > Privacy & Security and click Open Anyway.
- **Linux:** make the AppImage executable, then run it.

## What's new

- **Standing up from a crouch obeys the sound volume**, in MechWarrior 3 and Pirate's Moon (pm-v1.2.3). It used to play at full volume whatever the slider said.

MechWarrior 1 Remake is unchanged (1.0.6).

**Reporting a bug:** attach `mw3.log` from the game's data folder: `%APPDATA%\MicroProse\MechWarrior 3\` on Windows, `~/Library/Application Support/MicroProse/MechWarrior 3/` on Mac, `~/.local/share/MicroProse/MechWarrior 3/` on Linux (Pirate's Moon's is in `MicroProse/Pirate's Moon` beside it).
