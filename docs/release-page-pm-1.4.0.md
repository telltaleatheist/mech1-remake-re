Pirate's Moon on its own (mw3pm), without the launcher. The BattleTech launcher installs and updates it from this page.

**Most players want the launcher** (it installs MechWarrior 3, Pirate's Moon, MechWarrior 1 Remake and The Crescent
Hawk's Inception and keeps them up to date): [the BattleTech launcher 2.2.0](https://github.com/telltaleatheist/mw3-re/releases/tag/v2.2.0).

## Download

- **Windows:** `PM-Rebuild-Setup-pm-v1.4.0.exe` (or `mw3pm-pm-v1.4.0-win64.zip`)
- **Mac:** `PM-Rebuild-pm-v1.4.0-mac.dmg`
- **Linux:** `PM-Rebuild-pm-v1.4.0-x86_64.AppImage`

No game files are included. Started without them, Pirate's Moon finds your copy (an install, a disc or a disc image),
or offers to download the original game files. Installing over an earlier version keeps your pilots, saves, settings
and mods.

## What's new

- **A setup menu inside the game:** Cmd + Shift + F1 on the Mac, Shift + Alt + F1 elsewhere. It opens over any
  screen, a mission included, and pauses the game the way the original pauses when its window loses the focus (in a
  multiplayer game it can't pause, and says so). From it you can:
  - see which game files are in use, and CHANGE them;
  - report a problem, with the log at hand;
  - check Pirate's Moon's program and game files (an older install with no record gets Pirate's Moon's own check of
    its data files);
  - put every setting back to its default at once (a copy kept first);
  - open the UPGRADES page;
  - open your data folder.

  For the first three starts made without the launcher, a small reminder of the keys shows in the corner for ten
  seconds. Its × closes it.
- **Updates from inside the game:** the menu's UPDATES page checks for a newer Pirate's Moon, shows what is new in it,
  and updates in place, then starts the game again. Your pilots and settings are backed up first. Started on its own,
  the game checks once a day and asks when a new version is out; you can turn that off. Started from the launcher, it
  never asks, because the launcher updates it.
- **RUMBLE on the Game Options screen,** under RAW MOUSE (on to start). Turn it off if you play on mouse and keyboard
  and a plugged-in pad would otherwise rumble. Off, nothing rumbles, and an effect that is playing stops at once.
- **A gamepad's throttle keeps Assign Axis's zero point.** Bound at rest, the stick now stops the mech at rest and
  reaches full reverse pulled back, as the original does. Before, it ran at half throttle at rest. A joystick's
  throttle lever is unchanged.
- **The salvage and debriefing lists' scroll arrows click** as the salvage rows do.
- **Mobile field bases in multiplayer have their repair stations:** with mobile field bases allowed, each of the map's
  field base points gets a repair station, as in the original Pirate's Moon, except the map's fixed repair point.
  Before, none was set up.
