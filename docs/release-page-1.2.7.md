Pirate's Moon on its own (mw3pm), without the launcher. The BattleTech launcher installs and updates it from this page.

**Most players want the launcher** (it installs MechWarrior 3, Pirate's Moon and MechWarrior 1 Remake and keeps them up to date): [MechWarrior 3 Rebuild 1.3.5](https://github.com/telltaleatheist/mw3-re/releases/tag/v1.3.5).

## Download

- **Windows:** `PM-Rebuild-Setup-pm-v1.2.7.exe` (or `mw3pm-pm-v1.2.7-win64.zip`)
- **Mac:** `PM-Rebuild-pm-v1.2.7-mac.dmg`
- **Linux:** `PM-Rebuild-pm-v1.2.7-x86_64.AppImage`

You need your own Pirate's Moon: no game files are included. Installing over an earlier version keeps your pilots, saves, settings and mods.

## What's new

- **The launcher finds this copy by itself.** Pirate's Moon installed on its own records where it is when it starts, and the BattleTech launcher (1.3.5 or later) links it, so nothing is downloaded twice. The launcher never writes into this folder.
- The game itself plays the same as pm-v1.2.6.
