MechWarrior 3 on its own: the program and its own launcher. The BattleTech launcher installs and updates it from this
page.

**Most players want the launcher** (it installs MechWarrior 3, Pirate's Moon, MechWarrior 1 Remake and The Crescent
Hawk's Inception and keeps them up to date): [BattleTech launcher 2.2.0](https://github.com/telltaleatheist/mw3-re/releases/tag/v2.2.0).

## Download

- **Windows:** `MW3-alone-Setup-v1.8.1.exe` (or `MW3-alone-v1.8.1-win64.zip`)
- **Mac:** `MW3-alone-v1.8.1-mac.dmg`
- **Linux:** `MW3-alone-v1.8.1-x86_64.AppImage`

No game files are included. Started without them, MechWarrior 3 finds your copy (an install, a disc or a disc image),
or offers to download the original game files. Installing over an earlier version keeps your pilots, saves, settings
and mods.

## What's new

- **Windows zip players: 1.8.0's in-game UPDATE NOW could not replace the game's folder** (it said the update didn't
  finish). Download 1.8.1 by hand once; updates from inside the game work from then on. The Windows Setup, Mac and
  Linux copies weren't affected.
- **A new version found when the game starts is now a small notice in the corner,** with the keys to press, instead
  of the update screen over the game.
- **A copy installed at the very top of a drive says up front that it can't update itself.**
