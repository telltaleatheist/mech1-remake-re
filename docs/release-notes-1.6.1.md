# MechWarrior 3 Rebuild 1.6.1 (2026-11-27)

The Mac app is signed and notarized by Apple. Nothing in play changes.

## Changed

- **On a Mac, MechWarrior 3 opens like any other app.** The app and its
  download are signed with a Developer ID and notarized by Apple, so macOS
  no longer stops it the first time ("Not Opened") and there is no Open
  Anyway step in Privacy & Security.
- **The release's checksums are signed.** Beside `SHA256SUMS` the release
  carries `SHA256SUMS.sig`, so the launcher can take MechWarrior 3 from this
  project's mirror when GitHub cannot be reached, as it does the launcher.
- **The README's Music section** says how the CD audio comes in (GAME FILES,
  ADD FROM MY DISC), and the download page is now
  [reverse-engineered.com](https://reverse-engineered.com).

## Versions

- MechWarrior 3: 1.6.1. Your pilots, saves, settings, mods and game files are
  kept.
