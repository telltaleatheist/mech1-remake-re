# MechWarrior 3 Rebuild 1.8.1 (2026-11-28)

Updates from inside the game fixed for the Windows zip, and a quieter way of
saying a new version is out.

## Fixed

- **Windows zip players: 1.8.0's in-game UPDATE NOW could not replace the
  game's folder** (it said the update didn't finish). Download 1.8.1 by hand
  once; updates from inside the game work from then on. The Windows Setup, Mac
  and Linux copies weren't affected.

## Changed

- **A new version found when the game starts is now a small notice in the
  corner,** with the keys to press, instead of the update screen over the
  game. The notice shows for 15 seconds; the keys open the update question
  then or any time later in that session, and the menu's UPDATES page has it
  too.
- **A copy installed at the very top of a drive says up front that it can't
  update itself,** and to move its files into a folder or get the new version
  from its release page.

## Versions

- MechWarrior 3: 1.8.1. Your pilots, saves, settings, mods and game files are
  kept.
