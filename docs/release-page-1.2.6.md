Pirate's Moon on its own (mw3pm), without the launcher. The BattleTech launcher installs and updates it from this page.

**Most players want the launcher** (it installs MechWarrior 3, Pirate's Moon and MechWarrior 1 Remake and keeps them up to date): [MechWarrior 3 Rebuild 1.3.4](https://github.com/telltaleatheist/mw3-re/releases/tag/v1.3.4).

## Download

- **Windows:** `PM-Rebuild-Setup-pm-v1.2.6.exe` (or `mw3pm-pm-v1.2.6-win64.zip`)
- **Mac:** `PM-Rebuild-pm-v1.2.6-mac.dmg`
- **Linux:** `PM-Rebuild-pm-v1.2.6-x86_64.AppImage`

You need your own Pirate's Moon: no game files are included. Installing over an earlier version keeps your pilots, saves, settings and mods.

## What's new

- **Choosing your game files:** holding Shift as the game starts (or GAME FILES in the launcher) lists every copy of Pirate's Moon on your computer, with the one in use marked and what each is missing (the music, the full-quality sounds). Pick the one to use.
- **The copy you set up last is the one used**, before an older one your settings still name.
- The game itself plays the same as pm-v1.2.5.
