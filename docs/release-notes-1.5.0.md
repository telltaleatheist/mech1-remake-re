# MechWarrior 3 Rebuild 1.5.0 (2026-11-25)

The launcher, redrawn. MechWarrior 3 itself plays as in 1.4.1.

## New in the launcher

- **Sharp at any size.** The launcher drew a small picture and enlarged it; it
  now draws at the window's own size, text and edges included, with the same
  look. The window can be any size and is drawn while you drag its edge.
- **A game's gear page** lists its game files, the installed copy and any other
  copy, each with its buttons. GAME FILES and INSTALL FROM A DOWNLOADED FILE
  (was ADD FROM FILE) moved there from the bottom row, so they always act on
  the game you opened.
- **A linked copy can be uninstalled** from its page, not only unlinked: on the
  Mac and Linux it goes to the trash, on Windows its own uninstaller runs. Your
  pilots, saves, settings, mods and game files are kept.
- **CHECK FOR UPDATES** (was UPDATES) checks the launcher and every game again
  without leaving the main screen, for a launcher left open for days. A game
  with an update shows its UPDATE button. When the launcher has one, a box
  asks: UPDATE LAUNCHER, or UPDATE ALL to bring the games with it.
- One button style on every screen.

## Fixed

- A check for updates could now and then miss one: two checks running at once
  shared a temporary file.

## Versions

- Launcher and MechWarrior 3: 1.5.0.
- Pirate's Moon 1.2.9, MechWarrior 1 Remake 1.1.1 and The Crescent Hawk's
  Inception 1.0.0 are unchanged.

### Upgrading

Install over 1.4.1, or press UPDATE AVAILABLE in your launcher. Your pilots,
saves, settings, mods and game files are kept.
