## Before you install

- **You need your own games.** No game files are included: the launcher sets each game up from your install, disc or disc image, and copies what it needs, so you can delete your copy afterwards.
- **Upgrading from any earlier version:** install over it. Your pilots, saves, settings and mods are kept.
- **Mac:** the first time, macOS stops the app because it isn't signed. Open System Settings > Privacy & Security and click Open Anyway.
- **Linux:** make the AppImage executable, then run it.

## What's new

Setting up your games is simpler, and always your choice.

- **Your files are copied in:** an installed copy, a download or a disc image is copied into the game's own folder, so the original can be deleted. A game folder put next to the program is found whatever it is called.
- **What a game finds is only offered:** "USE THESE GAME FILES?" shows it on one button; INSTALL copies it in, and clicking the button lets you pick other files.
- **Choose again any time:** GAME FILES in the launcher, or hold **Shift** while a game starts.
- Pirate's Moon and MechWarrior (1989) are set up the same way.
- **MechWarrior 1 Remake 1.0.6:** its new name on the window and save folder (your saves move over by themselves), reach contracts you can actually reach, the first arctic map's defence contract back.
