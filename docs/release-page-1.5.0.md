This is the launcher (named BattleTech). It installs MechWarrior 3, Pirate's Moon, MechWarrior 1 Remake and The Crescent Hawk's Inception for you and keeps them up to date.

## Before you install

- **You need your own games.** No game files are included: each game sets itself up from your install, disc or disc image, and copies what it needs.
- **Upgrading:** install over it, or press UPDATE AVAILABLE in your launcher. Your pilots, saves, settings, mods and game files are kept.
- **Mac:** the first time, macOS stops the app because it isn't signed. Open System Settings > Privacy & Security and click Open Anyway.
- **Linux:** make the AppImage executable, then run it.

## What's new

- **The launcher is sharp at any window size**, with the same look; it draws at the window's own size instead of enlarging a small picture.
- **Each game's gear page** holds its game files, its installed copies and INSTALL FROM A DOWNLOADED FILE. A linked copy can be uninstalled there too.
- **CHECK FOR UPDATES** checks the launcher and every game without leaving the main screen. When the launcher has an update, a box offers UPDATE LAUNCHER, or UPDATE ALL for the games with it.
- A check for updates can no longer miss one.

MechWarrior 3 plays as in 1.4.1.

MechWarrior 3 is 1.5.0, Pirate's Moon 1.2.9, MechWarrior 1 Remake 1.1.1 and Inception 1.0.0 (unchanged).

**Reporting a bug:** attach `mw3.log` from the game's data folder: `%APPDATA%\BattleTech\MechWarrior 3\` on Windows, `~/Library/Application Support/BattleTech/MechWarrior 3/` on Mac, `~/.local/share/BattleTech/MechWarrior 3/` on Linux (Pirate's Moon's is in `BattleTech/Pirate's Moon` beside it). The launcher's own log is `mw3launcher.log` in the MechWarrior 3 folder.
