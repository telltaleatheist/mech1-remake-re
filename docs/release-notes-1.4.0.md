# MechWarrior 3 Rebuild 1.4.0 (2026-11-24)

The launcher, and Pirate's Moon's older data on Windows. MechWarrior 3 itself
plays as in 1.3.6.

## New in the launcher

- **Inception's game files are found and copied in the launcher.** PLAY on The
  Crescent Hawk's Inception opened the game's own setup window. With Inception
  1.0.0 the launcher finds your copy, shows it, and copies it in on its own
  screens, then starts the game. GAME FILES, on its settings page or after its
  PLAY, changes the copy later.
- **The pickers show every file**: zips too, where they used to show .bin and
  .iso. PICK A FOLDER is beside them, and a file or folder dropped on the window
  is taken as a pick.
- **ADD FROM MY DISC reads a .zip** (or .7z, .rar, .tar) of a disc image. It
  looked at the folder the zip was in and said it had no music.
- **A disc without music is a question, not an error**: PLAY WITHOUT MUSIC,
  PICK ANOTHER, PICK A FOLDER or BACK.
- **DOWNLOAD and INSTALL are the big button in the middle** of their screens,
  CHANGE FOLDER on the left and BACK on the right.
- PLAY is centred beside UPDATE.

## Fixed

- **Pirate's Moon's older data on Windows.** Launchers up to 1.3.1 put Pirate's
  Moon's folder inside MechWarrior 3's, and later versions didn't look there, so
  pilots, mods, music and saves seemed to be gone. The first start moves them
  across. No file is ever written over.

## Versions

- Launcher and MechWarrior 3: 1.4.0.
- Pirate's Moon: 1.2.9.
- MechWarrior 1 Remake: 1.1.1, unchanged.
- The Crescent Hawk's Inception: 1.0.0, from its own release.

Version numbers: features raise the second number, fixes the third, which can
go past 9.

### Upgrading

Install over 1.3.6, or press UPDATE AVAILABLE in your launcher. Your pilots,
saves, settings, mods and game files are kept.
