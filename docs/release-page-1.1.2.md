Each one holds MechWarrior 3, Pirate's Moon and the launcher.

## Before you install

- **You need your own game.** No game files are included: the launcher sets each game up from your install, disc or disc image.
- **Upgrading from 1.1.1, 1.1.0 or 1.0.x:** install over it. Your pilots, saves, settings and mods are kept.
- **Mac:** the first time, macOS stops the app because it isn't signed. Open System Settings > Privacy & Security and click Open Anyway.
- **Linux:** make the AppImage executable, then run it.

## What's new

- Both games are now ported whole, the developers' tools and unused code included (kept, not reachable in play, as in the original).
- Pirate's Moon behaves like its own in its menus, briefings, Instant Action line-ups, mission look, sensors, field bases and multiplayer; Ctrl+P saves a screenshot.
- Distant ground and walls no longer shimmer, in both games.
- Fixes: the pause's Escape silencing the mission, a missile locked on a mech that left the game, damaged model files, and the mod check with a world loaded.
