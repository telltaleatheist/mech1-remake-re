Each one holds MechWarrior 3, Pirate's Moon, MW1: Critical Hit and the launcher, now named BattleTech.

## Before you install

- **You need your own games.** No game files are included: the launcher sets each game up from your install, disc or disc image.
- **Upgrading from any earlier version:** install over it. Your pilots, saves, settings and mods are kept.
- **Mac:** the first time, macOS stops the app because it isn't signed. Open System Settings > Privacy & Security and click Open Anyway.
- **Linux:** make the AppImage executable, then run it.

## What's new

- Ultrawide screens (21:9, 32:9) filled in both games, without stretching.
- Joystick buttons 11 to 15 can be bound, and a stick plugged in while the game runs works.
- A new launcher: a card for each game, named BattleTech, in a window; on a Mac its file pickers open in a second instead of 7 to 12.
- MW1: Critical Hit 1.0.3.
