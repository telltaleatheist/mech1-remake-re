# MechWarrior 3 Rebuild 1.4.1 (2026-11-24)

A fix for the launcher's game files screens. MechWarrior 3 itself plays as in
1.4.0.

## Fixed

- **Inception's game files could not be changed.** With a copy already set up,
  FIND THE GAME found that copy again and went back to the main screen without
  opening a picker. GAME FILES, on Inception's settings page, now goes straight
  to PICK A FILE and PICK A FOLDER, so you can pick another copy, DOS or Amiga,
  at any time. Your saved games stay, and work with either version. The copy
  the launcher made before is replaced whole, so anything you added inside that
  folder goes with it; your own copy of the game is not touched.
- **A zip given to LINK AN INSTALL was refused.** That button is for the
  rebuild's own program; for Inception, a copy of the game picked there is now
  taken as its game files.

## New

- **PICK A FILE on every find screen**, beside PICK A FOLDER (a folder picker
  shows folders only). It opens on all files, with the types (downloads, disc
  images, programs) to choose from.
- Inception's GAME FILES says which version is in use, for example DOS 1.03.

## Versions

- Launcher and MechWarrior 3: 1.4.1.
- Pirate's Moon 1.2.9, MechWarrior 1 Remake 1.1.1 and The Crescent Hawk's
  Inception 1.0.0 are unchanged.

### Upgrading

Install over 1.4.0, or press UPDATE AVAILABLE in your launcher. Your pilots,
saves, settings, mods and game files are kept.
