- **Windows:** [MW3-Rebuild-Setup-v1.3.1.exe](https://github.com/telltaleatheist/mw3-re/releases/download/v1.3.1/MW3-Rebuild-Setup-v1.3.1.exe)
- **Mac:** [MW3-Rebuild-v1.3.1-mac.dmg](https://github.com/telltaleatheist/mw3-re/releases/download/v1.3.1/MW3-Rebuild-v1.3.1-mac.dmg)
- **Linux:** [MW3-Rebuild-v1.3.1-x86_64.AppImage](https://github.com/telltaleatheist/mw3-re/releases/download/v1.3.1/MW3-Rebuild-v1.3.1-x86_64.AppImage)

This is the launcher (named BattleTech). It installs MechWarrior 3, Pirate's Moon and MechWarrior 1 Remake for you and keeps them up to date.

## Before you install

- **You need your own games.** No game files are included: each game sets itself up from your install, disc or disc image, and copies what it needs.
- **Upgrading:** install over it, or press UPDATES in your launcher. Your pilots, saves, settings, mods and game files are kept.
- **Mac:** the first time, macOS stops the app because it isn't signed. Open System Settings > Privacy & Security and click Open Anyway.
- **Linux:** make the AppImage executable, then run it.

## What's new

- **Install each game where you want,** on any drive: INSTALL asks the first time (CHANGE FOLDER), and each game's setup can put its game files, music and converted movies there too. Your pilots, saves, settings and mods stay in your user folder.
- **Each game's setup shows its own name** instead of "MW3 Rebuild".

MechWarrior 3 is 1.3.1, Pirate's Moon 1.2.4, MechWarrior 1 Remake 1.0.8.

**Reporting a bug:** attach `mw3.log` from the game's data folder: `%APPDATA%\MicroProse\MechWarrior 3\` on Windows, `~/Library/Application Support/MicroProse/MechWarrior 3/` on Mac, `~/.local/share/MicroProse/MechWarrior 3/` on Linux (Pirate's Moon's is in `MicroProse/Pirate's Moon` beside it). The launcher's own log is `mw3launcher.log` in the MechWarrior 3 folder.
