# Pirate's Moon Rebuild 1.4.1 (2026-11-28)

Updates from inside the game, fixed for the Windows zip copy, and a quieter
way of saying a new version is out.

## If you play the Windows zip copy

Download 1.4.1 by hand this once and use it in place of your copy. Your
pilots, saves, settings and mods are in your data folder and are kept. The
in-game update in 1.4.0 could not move the game's folder aside and said the
update didn't finish, so 1.4.0 can't update itself to 1.4.1. From 1.4.1 on, it
can. The Windows Setup copy, the Mac and Linux were not affected and update as
usual.

## Fixed

- **Updating a Windows zip copy from inside the game works.** The update now
  leaves the game's folder before moving it, and starts the game again in it,
  a copy at a drive's root included.

## Changed

- **A new version found at the start is a small notice in the corner,** not
  the update question over the game. It reads UPDATE AVAILABLE with the
  version and the keys to press (Cmd + Shift + F1 on the Mac, Shift + Alt + F1
  elsewhere), stays for 15 seconds, and the game runs on underneath. The keys
  then open the update question. You can still turn the daily check off on the
  menu's UPDATES page.
- **A copy at the very top of a drive says up front that it can't update
  itself** (a drive can't be moved aside), with the release page to download
  from, instead of trying and failing.

## Versions

- Pirate's Moon: 1.4.1. Your pilots, saves, settings, mods and game files are
  kept.
